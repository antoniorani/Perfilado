PASO 02 / IDENTIFICACIÓN BIOMÉTRICA

¿De quién es
esta fotografía?

Tenemos una fotografía de referencia por persona. Ahora recibimos imágenes adicionales y debemos comprobar si pertenecen a alguien de la base de datos o a una identidad desconocida.

Vamos a utilizar modelos reales de reconocimiento facial para obtener embeddings, comparar distancias y descubrir cuándo una decisión aparentemente razonable se convierte en un error.

02.A / QUÉ VAMOS A HACER

Una imagen. Un vector. Una comparación.

01

Extraer

El modelo analiza cada rostro y obtiene un embedding de 128 números. No es una etiqueta de identidad.

02

Comparar

Calculamos la distancia euclidiana entre una imagen nueva y las fotografías de referencia.

03

Decidir

Si la distancia al candidato más próximo supera el umbral, el sistema responde «sin identificar».

Modelo: face-api.js, con pesos preentrenados ↗ · Fotografías: LFW ↗. Todo el cálculo se realiza en tu navegador.

No procesamos las 13.233 fotografías del dataset en directo: el experimento utiliza una muestra pequeña y reproducible para permitir su ejecución en clase. La calidad del detector puede impedir obtener algunos embeddings. Los resultados no son extrapolables a una situación real.
